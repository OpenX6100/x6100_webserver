Update the on-device GUI binary (/usr/sbin/x6100_gui) without reflashing the full SD image.

Package format

  • Upload a zip (outer filename can be anything).
  • The zip must contain exactly one file.
  • That file's name must be the lowercase hex sha256 of its contents (64 chars).
sha=$(sha256sum x6100_gui | awk '{print $1}')
cp x6100_gui "$sha"
zip -j whatever-you-like.zip "$sha"

After a successful upload the GUI restarts briefly (screen blanks).
